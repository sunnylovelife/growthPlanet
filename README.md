# 成长星球（growthPlanet）

为家庭场景打造的 PWA：孩子学习打卡赚「星币」，用星币兑换家长精选短视频；家长在手机后台确认作业、管理视频与账本。

## 快速开始

```bash
pnpm install
pnpm dev
```

- 孩子端：开发时一般为 `http://localhost:5173`（以 `scripts/dev.mjs` 为准）
- 家长后台：同级 dev 流程中的 admin 端口
- 测试：`pnpm test`
