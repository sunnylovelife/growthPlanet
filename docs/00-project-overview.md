## 1. 项目是什么

「成长星球」是一款面向家庭场景的 **PWA Web 应用**：孩子在 iPad 上打卡学习赚取「星币」，用星币兑换家长精选的短视频；家长在手机浏览器后台确认作业、管理视频、查看行为与账本。

| 角色 | 入口 | 说明 |
|------|------|------|
| 孩子 | `/` | 用户名 + 密码，建议「添加到主屏幕」全屏使用 |
| 家长 | `/admin` | 独立后台，手机优先 |

核心原则见 [项目目标](./01-goal.md)：只奖励优秀、服务端计账防刷、全程联网保证数据完整、家长一键操作。

## 3. 仓库结构

```
growthPlanet/
├── apps/
│   ├── kid/              # 孩子端 React + Vite
│   ├── admin/            # 家长后台 React + Vite
│   └── server/           # Node API、SQLite、定时任务、抖音下载/转码
├── packages/shared/      # 领域规则：周期、连续加成、视频计价、抽卡、卡牌与装扮常量
├── docs/                 # 产品与工程文档
├── scripts/dev.mjs       # 本地联调（前后端）
├── package.json          # pnpm workspace 根脚本
└── data/                 # 运行时数据（gitignore，部署在服务器上）
```

### 常用命令

| 命令 | 作用 |
|------|------|
| `pnpm dev` | 本地开发（孩子端、后台、API） |
| `pnpm test` | 运行共享领域 + 服务端 API/下载 等测试（当前 **30** 项全通过） |
| `pnpm start` | 生产模式启动 API（需先 `vite build` 孩子端与后台） |

### 技术栈（**实际实现**）

| 层 | 实现 | 备注 |
|----|------|------|
| 前端 | React 19 + TypeScript + Vite 7 | 孩子端 / 后台各一套入口 |
| 样式 | 手写 CSS（主题变量） | 设计文档中的 Tailwind 尚未采用 |
| PWA | `manifest.webmanifest` + 简易 `sw.js` | 未使用 `vite-plugin-pwa`；SW 不缓存 API/媒体 |
| 后端 | Node（`--experimental-strip-types`）+ 内置 `node:sqlite` | 单进程 HTTP |
| 共享逻辑 | `packages/shared` | 周期、计价、抽卡等与测试绑定 |
| 视频 | Playwright/Chromium → yt-dlp 兜底；ffmpeg 转码/封面 | 相册分片上传（5MB/片） |
| 部署 | 文档为 systemd + Caddy | 非 Docker Compose（与设计文档 11 节不同） |

## 5. 已开发功能（按模块）

以下为 **当前代码已具备** 的能力；与需求 ID 的对应关系见第 6 节。

### 5.1 平台与孩子端

- PWA：`standalone` manifest、iOS 全屏 meta、主屏幕引导文案
- 断网：约每 8 秒 `/api/ping`，连续失败则全屏遮罩并暂停视频
- 登录 / 退出；会话 Cookie
- 首页：当日任务（学校 / 厚海 / 游泳）、连续加成预览、待领取奖励、花费通知
- 作业：相机拍照提交（`capture=environment`）；重复照片哈希提示
- 钱包：余额（可为负时醒目样式）、账本明细
- 领奖：`RewardShow` 分幕（庆祝、金额滚动、周进度、连续升级、翻卡）；两套装扮主题差异（火箭 / 星光）
- 集卡：抽卡（含保底）、卡册按系列展示
- 装扮：昵称修改；**火箭少年 / 星光少女** 两套免费主题（动效与 UI 主题联动）
- 视频：列表、报价确认、签名地址播放、心跳、第 2 遍免费、断网停播
- 行为：客户端 `track` + `sessionStorage` 队列批量上报 `/api/events`
- 背单词：**仅占位**文案，无玩法

### 5.2 家长后台

- 登录（`portal: admin`）
- **今天**：一键完成作业；改学校作业截止时间；游泳「没去」；撤销误点（API 为 P1，已实现）；待确认照片列表；其他奖励/花费（多选孩子）
- **视频**：粘贴抖音分享文案导入；相册整文件分片上传与进度；下载/转码状态与进度条；上架/下架、重试、删除、预览播放
- **账本**：按孩子查看流水
- **数据**：今日概览（收支、观看次数/秒数）、行为列表、家长操作日志（刷新加载）
- **账号**：列出用户、改密码、退出（创建账号仅有 API，界面未做）

### 5.3 服务端与规则

- 任务周期：学校作业工作日 + 周五~周日合并；厚海每日；游泳周一/周四；每日任务生成与游泳 20:00 自动确认（定时任务）
- 连续加成、达标判定（截止时间北京时间）、待领取 `reward_claim`、领取入账与抽卡
- 视频递增计价、超长加价、购买与观看会话、媒体 Range、路径安全
- 抖音链接解析、下载队列、转码策略（720p 内 H.264/AAC MP4 可跳过转码）
- 防刷：金额服务端计算、幂等键（视频播放等）、账本只追加、按 IP 登录限流、照片感知哈希
- 经济规则：`GET/PUT /api/admin/settings`（**后台 UI 未接入**）
- 首次空库：创建 `parent` / `boy` / `girl`，随机初始密码（日志或 `GP_INIT_PASSWORD`）
